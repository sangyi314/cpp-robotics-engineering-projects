# C++ Robotics Engineering Project Series

A hands-on C++ project series focused on building practical software engineering skills and gradually applying them to robotics.

This repository is not intended to be a collection of isolated coding exercises.

Each project is designed to reinforce modern C++ concepts, improve engineering practices, and build a foundation for robotics software development.

The overall learning path is:

**Modern C++ -> Software Engineering -> Robotics -> Control -> ROS2**

---

## Objectives

The main goals of this project series are:

- Strengthen modern C++ programming skills through practical projects.
- Develop real software engineering habits using Git and CMake.
- Understand concurrency, resource management, and modular software design.
- Apply C++ knowledge to fundamental robotics problems.
- Build a foundation for later ROS2 and robotics development.
- Create projects that can be discussed and defended in technical interviews.

# C++ Multithreaded Robot Data Pipeline

A C++ learning project for building a simulated robot sensor
data pipeline and understanding multithreaded programming.


## Requirements

- Linux
- CMake 3.28 or newer
- A C++ compiler that supports the C++23 mode

## Build and Run

Run these commands from the repository root
(`cpp-robotics-engineering-projects`):

```bash
cmake -S cpp-multithreaded-robot-data-pipeline \
  -B cpp-multithreaded-robot-data-pipeline/build

cmake --build cpp-multithreaded-robot-data-pipeline/build

./cpp-multithreaded-robot-data-pipeline/build/robot_pipeline
```
